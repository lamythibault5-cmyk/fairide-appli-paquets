# fairide-appli-paquets

Ce dépôt ne contient que les **écrans compilés** de l'appli Fairride, déposés dans la release `appli-directe` par le
workflow « App mise à jour directe » du dépôt du site (privé). Les applis installées les téléchargent pour se mettre à
jour sans passer par les stores.

Ce sont les mêmes fichiers que le site fairride.be envoie à chaque visiteur : aucun code source, aucun commentaire,
aucune donnée. Rien d'autre ne doit jamais être déposé ici.
